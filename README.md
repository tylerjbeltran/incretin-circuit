# Inside the incretin circuit

Interactive explainer you can take apart in the browser. Remake of the Airsup Raptor 3 format for YourHealthRx.

## Open it

- Download `index.html` and open it locally, or
- Enable GitHub Pages on this repo (Settings → Pages → Deploy from `main` / root).

No build step. No CDN. Works offline.

## Controls

- **View:** Whole / Cutaway / Exploded
- **Follow:** All / Native GLP-1 / Analog
- **State:** Fasted / Fed
- **Signal slider:** receptor occupancy (educational, not a prescribed dose)

## What the meters mean

Qualitative signal intensity, not clinical endpoints or weight-loss percentages.

- Satiety: CNS circuit (area postrema, NTS/DVC, arcuate)
- Gastric emptying: slows via vagal pathways; long-acting agents show tachyphylaxis with chronic use
- Insulin: glucose-dependent (stays low when fasted)
- Nausea: same AP node that contributes to satiety

## Sources behind the labels

- Holst, Physiol Rev — native GLP-1 t½ ~1–2 min; ~10–15% intact to systemic circulation
- Deacon / DPP-4 literature — first-pass gut and liver degradation
- FDA Ozempic / Wegovy labels — semaglutide class t½ ~1 week; >99% albumin-bound; SC bioavailability ~89%
- Gabery et al., JCI Insight 2020 — semaglutide accesses circumventricular organs and adjacent NTS/arcuate; does not freely cross the BBB
- Wilding et al., NEJM 2021 (STEP-1) — efficacy context, not shown as a meter

Education, not a protocol. Compounded medications are not FDA-approved. Eligibility and prescribing are determined by a licensed clinician.
